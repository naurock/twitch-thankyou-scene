# Stream Danke — Read first

1. Extract the complete ZIP into a folder named `Stream-Danke` in your Windows Documents folder. Locate the actual Documents folder with **Win + R → `shell:Personal`**.
2. Open [GUIDE-EN.md](GUIDE-EN.md) and follow the setup instructions.
3. [Vorschau.html](Vorschau.html) displays sample names. Use the production `overlay.html` in OBS.
4. Create and compile the four C# actions in streamer.bot, then test the setup locally.

The files do not configure your applications automatically. Collection begins only after setup and the start of a session.
